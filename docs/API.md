# Current API

Base URL: `http://127.0.0.1:8000`

- `GET /api/health/`
- `POST /api/auth/register/`
- `POST /api/auth/login/`
- `POST /api/auth/refresh/`
- `GET /api/auth/me/`
- `POST /api/auth/logout/`
- `GET /api/auth/admin-only/`
- `GET /api/auth/manager-or-admin/`

The authentication endpoints use JWT.
